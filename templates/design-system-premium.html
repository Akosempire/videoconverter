♿ Accessibility & performance

— Build notes

PRESERVE ENGINE

Do not rebuild — upgrade within the existing Flask + moviepy codebase. Preserve convert_mov_to_mp4, quality/resolution/audio handling, 500 MB limit, and H.264/AAC output. Keep the multipart form usable without JavaScript. Add motion only if not already present; otherwise use the current animation system. Verify every state before shipping: empty, drag-valid, invalid file, file-ready, preview-unsupported, ready-to-convert, uploading (measured %), converting (indeterminate), complete, error, removed — plus 320/390/768/1024/1280/1920 widths and reduced-motion.
